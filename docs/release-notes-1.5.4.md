# Release notes — 1.5.4 (versionCode 18)

Follows 1.5.3 (versionCode 17). New since then: Russian name days, the church each
calendar follows in the language picker, corrected scripture readings in every
calendar, complete Russian saint names and moving Russian commemorations on their
proper days, and data corrections without app updates (BundledData.REVISION = 10;
archive dataRevision 10 published 2026-09-29). iOS equivalent: 1.4.7 (build 20).

**Release name (Play Console, internal only, ≤50 chars):**
```
1.5.4 (18) — Name days, readings fixed
```

store listing has languages for.
