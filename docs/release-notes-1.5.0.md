# Release notes — 1.5.0 (versionCode 14)

Production is currently on **1.4.2 (vc 11)**. Version 1.4.3 (vc 12) shipped only to
internal/closed testing and 1.5.0 (vc 13) to open testing, so the fasting-banner fix
and everything in 1.5.0 are new to production users. Notes below cover all of it.

versionName stays **1.5.0** — the code is identical to what open testing already has;
only the versionCode is bumped so the artifact can be uploaded again.

**Release name (Play Console, internal only, ≤50 chars):**
```
1.5.0 (14) — All years 2024–2099
```

Play limit for "What's new" is **500 characters per language**.

---

## English (en-US)

```
• Every year from 2024 to 2099 is now available — browse far back or far ahead through the liturgical calendar.
• Years 2025–2030 stay fully offline in the app; any other year downloads once and is then kept on your device.
• Fixed the fasting banner sometimes showing a fast that had already ended or not yet begun.
• Updated for Android 16.
• Stability and performance improvements.
```
